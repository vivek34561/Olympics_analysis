# 🏅 Olympics Data Analysis Project

Welcome to the **Olympics Data Analysis Project**! This project captures the data-driven spirit of the Olympic Games and applies it to uncover meaningful patterns, trends, and insights from historical data. As a data science enthusiast, I created this project to showcase my analytical capabilities while celebrating the global unity of the Olympic movement.

🔗 **Live App**: [Streamlit App](https://olympicsanalysis-rnegm7gkcgfrt3xyy4c4ul.streamlit.app/)

---

## 🎉 Introduction

The Olympics is more than just a sports event—it's a global celebration of excellence, perseverance, and diversity. This project explores historical Olympic data, analyzing how countries and athletes have performed over the years. It aims to deliver a compelling story through data, visuals, and interactivity.

---

## 💡 Motivation

With the world focused on the Paris 2024 Olympics, I was inspired to apply my data science skills to something timely and globally relevant. This project allowed me to explore real-world data, gain hands-on experience in data cleaning, analysis, and visualization, and build a functional web app using Streamlit.

I was also inspired by a great video tutorial from CampusX, which helped lay the foundation for this custom version of the Olympics Analysis.

---

## 📊 Data Source

* **Kaggle Olympics Dataset**: Historical data about athletes, events, and medal tallies from the modern Olympic Games.

  * Dataset Link: [Kaggle – Olympic History Dataset](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

---

## 🚀 Features

* **Data Cleaning & Preprocessing**
  Merged and refined datasets, handled missing values, and optimized for analysis.

* **Descriptive Statistics**
  Summary stats on athletes, countries, and events, using pivot tables and aggregation.

* **Trend Analysis**
  Visual trends of participation, medal tallies, and event expansion over the years.

* **Country-Wise Performance**
  Medal counts by country and sport, including top-performing nations and historical dominance.

* **Athlete Analysis**
  Insights into age, gender distribution, performance metrics, and sport specialization.

* **Interactive Visualizations**
  Built using Streamlit, Plotly, Seaborn, and Matplotlib for exploratory and comparative analysis.

---

## 🔍 Key Analysis Sections

* **Olympics Growth Timeline**
  Visualizing participation from nations, athletes, and events across editions.

* **Top Nations Overview**
  Comparing medal statistics and success rates of major countries.

* **Sport-Specific Focus**
  Dive deep into how different sports evolved and which nations dominate.

* **Athlete Demographics**
  Analyze gender representation, age distribution, and medal trends by individual athletes.
